# 1.0.6

- Equipped stones start on their hotkey. The "cannot be activated" check was a personal kill counter that did not have the boss kills.

# 1.0.5

- F and Shift+F start the equipped stones directly. The press is read before Valheim consumes the guardian-power button.

# 1.0.4

- F and Shift+F now register. Valheim reserves F as the guardian-power button, so the old key check never saw it.

# 1.0.3

- Hotkeys for the first and second equipped boss power are in this mod's config. Clicking the stones sets which power is in each slot. Holding the key no longer rotates them.

# 1.0.2

- Shift+F no longer starts Eikthyr and no longer aborts the second power. A bare F still starts the first power.

# 1.0.1

- Shift+F (or any modifier + guardian-power key) no longer starts the first equipped power. Passive Powers can fire slot 2.

# 1.0.0

- Divine Favor tap bursts the first equipped Passive Power. Hold rotates which equipped power is first.
- TalentTree's own Divine Favor cycle is removed. Cooldown reduction is unchanged.
- Client only. Needs TalentTree and Passive Powers.
